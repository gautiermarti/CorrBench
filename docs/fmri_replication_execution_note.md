# ABIDE replication execution note

The frozen replication protocol's text gives an approximate declaration time
of 11:25 UTC. The initial queue actually started at 11:23:45 UTC on October 5;
that textual timestamp is not an accurate launch timestamp. The protocol file,
configurations and source hashes were captured before the corresponding jobs
were launched. This is an exploratory extension of an already inspected site,
not a formal prospective preregistration or a new holdout.

The initial node-flow commands failed because the shared installed package
predated those CLI modules. The first additional DiffeoCFM training job completed,
then its newer sampling module had the same import issue. Recovery supplied
explicit paths to the frozen checkout sources; it did not change scientific
code, data, configurations or budgets. The completed DiffeoCFM training job was
retained after verifying hashes, rather than silently restarted.

Original failure logs/ledgers, recovered plans and
execution_recovery.json remain in the local replication artifact directory.
The final utility audit checks recovered plan and output hashes. This note leaves
the original frozen protocol unchanged so its recorded fingerprints remain valid.
