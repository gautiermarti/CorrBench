# Coordinated candidate 0.1.0rc1

CorrBench, CorrFlow and CorrGAN use the same prerelease version and exact
compatible benchmark revision. This candidate has not been publicly released
or assigned an archival DOI. The earlier `0.1.0.dev0` teaching wheels, checkpoint
and source archives remain immutable artifacts identified by their own hashes.

This candidate adds the DDPM budget/resume/native-selection tools and audited
brain atlas/110-region sensitivity materials. The leaderboard contains 43
records under nine separate views, retaining all original 37. The original
financial, 111-label brain and weather findings remain intact. The longer DDPM
fit suite is queued; no new result is inferred from implemented training tools.

Install all three compatible wheels together, or clone the three repositories
as siblings and install the benchmark before the models. The models' exact
benchmark Git pins identify compatible source. The public export rewrites the
pins to its reviewed public snapshot; intended URLs are not evidence of hosting.

Python 3.12 on Linux aarch64 with CPU PyTorch is the tested platform. Scientific
dependencies and their exact tested versions accompany the audit. `.[atlas]`
adds NiBabel for the source-mask diagnostic; it is not a core runtime dependency.
GPU retraining, other-platform verification and hosted CI remain distinct.

The release audit builds wheels and source archives, installs the wheels and
runs all tests, then actually reinstalls from the source archives before the
second test pass. It compares installed module bytes with both the checkout and
extracted source, checks dependency consistency, bundled README images and every
console command's help path. Functional tests and examples cover scientific
behavior; a help check alone does not establish end-to-end model fidelity.

No financial or participant-level matrices are in these software archives.
The bundled six-variable model and its data are explicitly synthetic teaching
assets. Dataset and model rights, full retraining, final manuscript identifiers,
and an external person's reproduction remain separately tracked.

The [development distribution audit](release_validation_rc1_20261006.json)
passes all 107 tests after wheel installation and all 107 again after installation
from source archives. All 29 console entry points and eight additional module
help paths pass. The public snapshot receives its own subsequent audit because
its installation pins and documentation are adapted for export.
